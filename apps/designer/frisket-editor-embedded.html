A host page, with two editors inside it

Each panel below is a <frisket-editor> with a document of its own: typing in one changes nothing in the other, and each tells the page what its own checks found. This page's stylesheet is not the editors', and neither reaches the other - they draw in shadow roots. What crosses the boundary is the palette, the custom properties set on each element, because that is what a theme is meant to be.

The letter is also handed this page's merge fields - the button with braces in its toolbar. A field goes in at the caret as its token, which the engine fills from the case data when it prints; a picture field is a block the data fills. The values come formatted by the host, so a field's kind only sorts the menu.
